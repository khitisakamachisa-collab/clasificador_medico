Resumen consolidado para tu CMMS (con la corrección del tomógrafo)

La filosofía que hemos acordado es:

Clasificar al nivel EMDN más bajo posible únicamente cuando la información disponible lo permite.

Si el nombre del equipo no contiene información suficiente para distinguir entre varias hojas terminales, se debe utilizar el último nodo válido conocido y marcarlo como pendiente de desambiguación.

4. Tomógrafo computarizado
Código EMDN recomendado

Z110306

Descripción

COMPUTED TOMOGRAPHS (CT)

Justificación

El nombre "Tomógrafo computarizado" únicamente permite identificar la familia CT.

Existen múltiples hojas terminales:

Plain Text
Z11030601 Hasta 2 cortes
Z11030602 >2 y <16 cortes
Z11030603 16 a 63 cortes
Z11030605 64 a 127 cortes
Z11030606 128 a 255 cortes
Z11030607 256 o más cortes

Como el número de cortes no está presente en el nombre del equipo, no es posible seleccionar una hoja terminal con certeza.

Por tanto, la clasificación correcta es:

Plain Text
Z110306

hasta disponer de información adicional.

Recomendación para la IA de clasificación

Yo implementaría esta regla general:

Plain Text
1. Buscar la categoría EMDN más específica posible.
 
2. Si existe una única hoja terminal compatible:
devolver la hoja terminal.
 
3. Si existen varias hojas terminales posibles:
devolver el último nodo común.
 
4. Registrar:
requiere_desambiguacion = true

Corrección menor en tu redacción (para que sea precisa al documentar):

Z110306 tiene término COMPUTED TOMOGRAPHS (CT) (nivel 4, NO terminal). No es que "existen múltiples hojas terminales" — es que existen 01-07 y no sabes cuál. El nodo Z110306 es válido como referencia, pero debe marcarse requisito_desambiguacion = true.
Sobre la ubicación por categoría (ya está implícito en tu resumen, solo confirmo que es coherente con Z = equipo médico):

Terapia Quirúrgica → Quirófanos / Endoscopia
Diagnóstico por Imagen → Cardiología / Ecocardiografía / Radiología
Sistemas de Infusión → UCI / Hospitalización / Quirófano
